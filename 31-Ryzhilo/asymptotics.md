## Обозначения и способ подсчёта

- `n` — длина массива; в прямоугольной матрице `n` — строки, `m` — столбцы.
- В №19 `n` и `m` — длины двух массивов.
- В №18 `k` — количество чётных значений, в №4 `c` — число совпадений.
- В №20 `R = max − min + 1`, в №22 `g` — количество различных значений.
- В №35 `q` — число запросов. В №56 матрицы имеют размеры `n × m` и `m × k`.
- `B` — максимальная длина участвующего аккумулятора BigInteger в битах.

Время включает чтение ввода и формирование вывода. Для обычных int/long/double
арифметическое действие считается операцией постоянной стоимости.
Размер записи одного машинного числа ограничен типом и условиями задачи.
Внутренние буферы Scanner/PrintStream, JVM, тестового окружения и внешнего получателя вывода
в алгоритмическую память не включаются. Если сам код создаёт StringBuilder, его память учитывается.

**Общая память** включает входные массивы, которые программа создаёт при чтении.
**Дополнительная память** — рабочие структуры сверх сохраняемого входа.
Если вход вообще не сохраняется, все реально создаваемые структуры считаются рабочей памятью.
Для №35 это префиксный массив; для №50 и №52 — массивы накопителей столбцов.

`O(f)` обозначает верхнюю оценку, `Θ(f)` — точный порядок роста.
Если лучший случай не указан отдельно, приводится оценка худшего случая
или явно указанная средняя оценка для HashMap.
Для BigInteger в основной таблице указано число арифметических операций;
дополнительная побитовая оценка приведена в соответствующем разделе.
Число живых объектов BigInteger и их суммарное число бит — разные показатели.

В №1 память равна Θ(1): текущий код не хранит массив.
В №20 отдельно рассмотрены прямой подсчёт и стабильные проходы подсчёта по байтам.

## Задача 1. Максимум и минимум

### Расчёт времени

После чтения первого элемента выполняются n−1 итераций. На каждой — не более двух сравнений. Поэтому T(n) = a + b(n−1) = Θ(n).

**Итог:** Θ(n).

### Расчёт памяти

Массив не создаётся. Хранятся размер, счётчик, текущее значение, минимум и максимум. Число переменных не зависит от n: S(n) = Θ(1).

**Общая память:** Θ(1). **Дополнительная память:** Θ(1).

## Задача 2. Индекс первого вхождения

### Расчёт памяти

## Задача 13. Сортировка выбором

### Расчёт времени

Внутренний цикл делает (n−1) + (n−2) + … + 1 = n(n−1)/2 сравнений. Порядок входных данных это число не меняет. Чтение, обмены и вывод добавляют O(n). Итого Θ(n²) и в лучшем, и в худшем случае.

**Итог:** Θ(n²).

### Расчёт памяти

Массив длины n занимает Θ(n). Индексы и временная переменная обмена — Θ(1).

**Общая память:** Θ(n). **Дополнительная память:** Θ(1).

## Задача 14. Сортировка вставками

### Расчёт времени

В худшем случае вставка i-го элемента сдвигает i предыдущих. Сумма сдвигов 1 + … + (n−1) = n(n−1)/2, поэтому Θ(n²). Если массив уже упорядочен по невозрастанию, сдвигов нет и выполняется Θ(n) проверок. Ввод и вывод линейны.

**Итог:** худшее Θ(n²), лучшее Θ(n).

### Расчёт памяти

Сортировка изменяет исходный массив. Кроме n элементов нужны только value и индексы: Θ(1) дополнительной памяти.

**Общая память:** Θ(n). **Дополнительная память:** Θ(1).

## Задача 15. Пузырьковая сортировка с подсчётом обменов

### Расчёт времени

**Итог:** худшее Θ(n²), лучшее Θ(n).

### Расчёт памяти

Массив занимает Θ(n). Флаг, индексы, временное значение и счётчик обменов long занимают Θ(1).

**Общая память:** Θ(n). **Дополнительная память:** Θ(1).

## Задача 16. Сортировка по модулю

### Расчёт времени

Сортировка слиянием удовлетворяет T(n) = 2T(n/2) + Θ(n). На каждом из Θ(log n) уровней обрабатываются Θ(n) значений. Сравнение модулей двух int через long имеет постоянную стоимость. Итого Θ(n log n).

**Итог:** Θ(n log n).

### Расчёт памяти

Исходный массив и буфер имеют длину n. Стек рекурсии занимает Θ(log n). Дополнительно Θ(n + log n) = Θ(n), всего также Θ(n).

**Общая память:** Θ(n). **Дополнительная память:** Θ(n).

## Задача 17. Сортировка по сумме цифр

### Расчёт времени

Сортировка слиянием выполняет Θ(n log n) сравнений. Сумма цифр вычисляется при сравнении заново, но у неотрицательного int не больше 10 цифр, поэтому сравнение O(1). Для чисел с переменным количеством d цифр верхняя оценка была бы O(n log n · d).

<a id="task-56"></a>

## Задача 56. Умножение матриц

### Расчёт времени

Читаются nm + mk элементов. Результат содержит nk ячеек, каждая вычисляется за m произведений и сложений. T(n,m,k) = Θ(nm + mk + nkm) = Θ(nmk) при положительных размерах. Для аккумулятора BigInteger B = O(64 + log(m + 1)); побитовая верхняя оценка вычислительной части O(nmkB).

**Итог:** Θ(nmk) арифметических операций.

### Расчёт памяти

Хранятся обе входные матрицы: Θ(nm + mk) машинных слов. Матрица результата не сохраняется: очередная ячейка сразу выводится. Сверх входных матриц используется постоянное число BigInteger, то есть O(B) бит. В условии указано O(nk) памяти; трактовка её как общей или дополнительной требует уточнения. Нельзя заменять фактическую общую оценку Θ(nm + mk) на O(nk) без пояснения.

**Общая память:** Θ(nm + mk) слов и O(B) бит. **Дополнительная память:** O(B) бит.
