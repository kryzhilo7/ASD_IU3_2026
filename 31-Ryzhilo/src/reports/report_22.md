# Задача 22. Сортировка по частоте

### Условие и формат

Требуется получить: массив, отсортированный по убыванию частоты встречаемости элементов. При равных частотах — по возрастанию значения.

**Ввод:** Размер n, затем n целых элементов массива.

### Идея решения

Используются массивы значений и частот. Сначала все частоты равны нулю, поэтому пирамидальная сортировка упорядочивает значения по возрастанию. Затем равные значения объединяются в группы в начале массивов. Второй запуск пирамидальной сортировки упорядочивает группы по убыванию частоты и возрастанию значения. Каждая группа выводится столько раз, какова её частота.

### Асимптотика

- Время: O(n log n).
- Память: O(n).

Первый запуск пирамидальной сортировки требует O(n log n). Подсчёт групп требует O(n), второй запуск для g≤n групп — O(g log g), вывод — O(n). Два массива имеют длину n.

### Примеры ручной проверки

**Пример 1. Основной пример.** Проверяет основной результат алгоритма на конкретном вводе.

Ввод:

```text
5
3 -1 2 0 3
```

Ожидаемый вывод:

```text
3 3 -1 0 2
```

**Пример 2. Граничный пример.** Проверяет специальный или граничный случай входных данных.

Ввод:

```text
7
5 3 5 3 -1 -1 7
```

Ожидаемый вывод:

```text
-1 -1 3 3 5 5 7
```
