# Задача 55. Сумма элементов на побочной диагонали

### Условие и формат

Требуется получить: сумма элементов на побочной диагонали (от правого верхнего угла к левому нижнему).

**Ввод:** Размер n, затем квадратная матрица n×n по строкам.

### Идея решения

При чтении складывать ячейки с i+j=n−1 в long.

### Асимптотика

- Время: O(n²) с учётом ввода.
- Память: O(1).

Чтение квадратной матрицы требует n² операций. При чтении выбираются n диагональных элементов; хранится только long-сумма.

### Примеры ручной проверки

**Пример 1. Основной пример.** Проверяет основной результат алгоритма на конкретном вводе.

Ввод:

```text
3
1 2 3
4 5 6
7 8 9
```

Ожидаемый вывод:

```text
15
```

**Пример 2. Граничный пример.** Проверяет специальный или граничный случай входных данных.

Ввод:

```text
2
0 1
2 3
```

Ожидаемый вывод:

```text
3
```

**Пример 3. Побочная диагональ.** Проверяется выбор ячеек i+j=n−1.

Ввод:

```text
2
1 2
3 8
```

Ожидаемый вывод:

```text
5
```
