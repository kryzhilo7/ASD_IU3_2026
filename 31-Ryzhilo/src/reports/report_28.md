# Задача 28. Медиана массива

### Условие и формат

Требуется получить: медиана массива. При нечётном n — элемент посередине после сортировки. При чётном n — среднее арифметическое двух центральных элементов (как число с плавающей точкой).

**Ввод:** Размер n, затем n целых элементов массива.

### Идея решения

Отсортировать массив. Для нечётной длины взять центральный элемент; для чётной сложить два центральных в long и разделить на 2.0.

### Асимптотика

- Время: O(n log n).
- Память: O(n); дополнительно O(1).

Построение двоичной кучи линейно, затем выполняется O(n) извлечений с восстановлением высотой O(log n). Последующие выбор элемента, сравнение или подсчёт не превосходят O(n). Сортировка выполняется на месте.

### Примеры ручной проверки

**Пример 1. Основной пример.** Проверяет основной результат алгоритма на конкретном вводе.

Ввод:

```text
5
3 -1 2 0 3
```

Ожидаемый вывод:

```text
2
```

**Пример 2. Граничный пример.** Проверяет специальный или граничный случай входных данных.

Ввод:

```text
2
9 2
```

Ожидаемый вывод:

```text
5.5
```

**Пример 3. Чётная длина и переполнение int.** Два центральных значения складываются после расширения до long.

Ввод:

```text
2
2147483647 2147483647
```

Ожидаемый вывод:

```text
2147483647.0
```
