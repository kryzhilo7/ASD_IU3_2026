# Задача 32. Сумма произведений пар

### Условие и формат

Требуется получить: сумма произведений всех пар элементов a_i * a_j для i < j.

**Ввод:** Размер n, затем n целых элементов массива.

### Идея решения

Хранить сумму предшествующих элементов P. При чтении x добавить P*x к ответу и x к P. Каждая пара учитывается один раз по правому концу. Для точного ответа использовать BigInteger.

### Асимптотика

- Время: O(n) арифметических операций.
- Память: O(1) чисел BigInteger.

На элемент выполняется постоянное число арифметических операций. Массив сохранять не требуется: в памяти остаются только аккумуляторы. BigInteger не имеет постоянной битовой стоимости: она зависит от длины чисел; при заданных ограничениях n и int длина накопленных результатов ограничена.

### Примеры ручной проверки

**Пример 1. Основной пример.** Проверяет основной результат алгоритма на конкретном вводе.

Ввод:

```text
5
3 -1 2 0 3
```

Ожидаемый вывод:

```text
13
```

**Пример 2. Граничный пример.** Проверяет специальный или граничный случай входных данных.

Ввод:

```text
4
2147483647 2147483647 2147483647 2147483647
```

Ожидаемый вывод:

```text
27670116084794523654
```
