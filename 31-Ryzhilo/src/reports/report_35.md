# Задача 35. Префиксные суммы

### Условие и формат

Требуется получить: для каждого запроса — сумму элементов с индексами от l до r включительно.

**Ввод:** Размер n, n элементов массива, число запросов q, затем q пар l r. Границы включительные, индексация с нуля.

### Идея решения

Построить prefix длины n+1. Сумма включительного диапазона [l,r] равна prefix[r+1]−prefix[l].

### Асимптотика

- Время: O(n+q), запрос O(1).
- Память: O(n).

Построение n+1 префиксных сумм требует O(n) времени и памяти. На каждый из q запросов выполняется одно вычитание.

### Примеры ручной проверки

**Пример 1. Основной пример.** Проверяет основной результат алгоритма на конкретном вводе.

Ввод:

```text
5
3 -1 2 0 3
3
0 4
0 0
4 4
```

Ожидаемый вывод:

```text
7
3
3
```

**Пример 2. Граничный пример.** Проверяет специальный или граничный случай входных данных.

Ввод:

```text
2
9 2
3
0 1
0 0
1 1
```

Ожидаемый вывод:

```text
11
9
2
```

**Пример 3. Границы и одноэлементный запрос.** Проверяется включительность обеих границ.

Ввод:

```text
3
1 2 3
2
0 2
1 1
```

Ожидаемый вывод:

```text
6
2
```
