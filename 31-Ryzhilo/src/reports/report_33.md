# Задача 33. Количество инверсий

### Условие и формат

Требуется получить: количество пар (i, j) таких, что i < j и a_i > a_j.

**Ввод:** Размер n, затем n целых элементов массива.

### Идея решения

Сортировка слиянием: когда правый элемент меньше левого, он образует инверсии со всеми оставшимися элементами левой половины. Счётчик long.

### Асимптотика

- Время: O(n log n).
- Память: O(n).

На каждом уровне слияния суммарно обрабатываются все сортируемые элементы, уровней логарифмически много. Временный буфер имеет линейный размер, стек рекурсии — логарифмический.

### Примеры ручной проверки

**Пример 1. Основной пример.** Проверяет основной результат алгоритма на конкретном вводе.

Ввод:

```text
5
3 -1 2 0 3
```

Ожидаемый вывод:

```text
4
```

**Пример 2. Граничный пример.** Проверяет специальный или граничный случай входных данных.

Ввод:

```text
2
9 2
```

Ожидаемый вывод:

```text
1
```

**Пример 3. Равные элементы не образуют инверсии.** Инверсия определяется строгим сравнением.

Ввод:

```text
3
2 2 2
```

Ожидаемый вывод:

```text
0
```
