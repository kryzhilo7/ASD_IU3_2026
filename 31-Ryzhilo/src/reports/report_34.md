# Задача 34. Максимальная сумма подмассива

### Условие и формат

Требуется получить: максимальная сумму непрерывного подмассива.

**Ввод:** Размер n, затем n целых элементов массива.

### Идея решения

Алгоритм Кадане: лучший непустой отрезок, заканчивающийся здесь, либо начинается текущим элементом, либо продолжает предыдущий. Начинать с первого значения, чтобы обработать полностью отрицательный массив.

### Асимптотика

- Время: O(n).
- Память: O(1).

Выполняется постоянное число линейных проходов по n элементам. Достаточно постоянного числа аккумуляторов и индексов; исходные элементы не сохраняются.

### Примеры ручной проверки

**Пример 1. Основной пример.** Проверяет основной результат алгоритма на конкретном вводе.

Ввод:

```text
5
3 -1 2 0 3
```

Ожидаемый вывод:

```text
7
```

**Пример 2. Граничный пример.** Проверяет специальный или граничный случай входных данных.

Ввод:

```text
3
-9 -2 -6
```

Ожидаемый вывод:

```text
-2
```

**Пример 3. Все значения отрицательные.** Подмассив непустой; ответ не должен ошибочно равняться нулю.

Ввод:

```text
3
-9 -2 -6
```

Ожидаемый вывод:

```text
-2
```
