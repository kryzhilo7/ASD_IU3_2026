# Задача 26. Произведение элементов

### Условие и формат

Требуется получить: произведение всех элементов по модулю 10^9 + 7.

**Ввод:** Размер n, затем n целых элементов массива.

### Идея решения

При чтении каждое число приводится к остатку по модулю 1000000007. Если остаток отрицательный, к нему прибавляется модуль. После умножения аккумулятора на остаток снова берётся остаток. Оба множителя меньше модуля, поэтому промежуточное произведение помещается в long.

### Асимптотика

- Время: O(n).
- Память: O(1).

Выполняется постоянное число линейных проходов по n элементам. Достаточно постоянного числа аккумуляторов и индексов; исходные элементы не сохраняются.

### Примеры ручной проверки

**Пример 1. Основной пример.** Проверяет основной результат алгоритма на конкретном вводе.

Ввод:

```text
5
3 -1 2 0 3
```

Ожидаемый вывод:

```text
0
```

**Пример 2. Граничный пример.** Проверяет специальный или граничный случай входных данных.

Ввод:

```text
2
-1 2
```

Ожидаемый вывод:

```text
1000000005
```

**Пример 3. Отрицательное произведение.** Остаток нормализуется в диапазон от 0 до 1000000006.

Ввод:

```text
2
-2 3
```

Ожидаемый вывод:

```text
1000000001
```
