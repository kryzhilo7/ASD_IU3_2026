# Задача 39. Циклический сдвиг вправо

### Условие и формат

Требуется получить: массив, циклически сдвинутый вправо на k позиций.

**Ввод:** Размер n, затем n целых элементов массива. После массива вводится k.

### Идея решения

Перевести сдвиг вправо на k в сдвиг влево на (n−k)%n и применить три разворота. k читается как long.

### Асимптотика

- Время: O(n).
- Память: O(n); дополнительно O(1).

Выполняется постоянное число линейных проходов по n элементам. Исходный массив хранит n значений. Преобразование выполняется на месте, сверх массива используется O(1) памяти.

### Примеры ручной проверки

**Пример 1. Основной пример.** Проверяет основной результат алгоритма на конкретном вводе.

Ввод:

```text
5
3 -1 2 0 3
0
```

Ожидаемый вывод:

```text
3 -1 2 0 3
```

**Пример 2. Граничный пример.** Проверяет специальный или граничный случай входных данных.

Ввод:

```text
2
9 2
-1
```

Ожидаемый вывод:

```text
2 9
```

**Пример 3. Сдвиг на длину.** После нормализации сдвиг равен нулю.

Ввод:

```text
4
1 2 3 4
4
```

Ожидаемый вывод:

```text
1 2 3 4
```
