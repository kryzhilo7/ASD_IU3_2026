# Задача 51. Максимум в каждой строке

### Условие и формат

Требуется получить: массив из n элементов — максимальных значений в каждой строке.

**Ввод:** Два положительных размера n m, затем n строк по m целых чисел.

### Идея решения

Для каждой строки поддерживать максимум, начиная с Integer.MIN_VALUE.

### Асимптотика

- Время: O(nm).
- Память: O(1).

Обрабатывается n*m ячеек; число проходов постоянно. Достаточно максимума текущей строки.

### Примеры ручной проверки

**Пример 1. Основной пример.** Проверяет основной результат алгоритма на конкретном вводе.

Ввод:

```text
2 3
1 2 3
4 5 6
```

Ожидаемый вывод:

```text
3 6
```

**Пример 2. Граничный пример.** Проверяет специальный или граничный случай входных данных.

Ввод:

```text
3 1
1
2
3
```

Ожидаемый вывод:

```text
1 2 3
```

**Пример 3. Полностью отрицательные строки.** Нельзя начинать поиск максимума с нуля.

Ввод:

```text
2 2
-5 -2
-9 -4
```

Ожидаемый вывод:

```text
-2 -4
```
