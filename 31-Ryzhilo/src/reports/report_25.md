# Задача 25. Сумма элементов

### Условие и формат

Требуется получить: сумма всех элементов.

**Ввод:** Размер n, затем n целых элементов массива.

### Идея решения

Накопить сумму в long во время чтения.

### Асимптотика

- Время: O(n).
- Память: O(1).

Выполняется постоянное число линейных проходов по n элементам. Достаточно постоянного числа аккумуляторов и индексов; исходные элементы не сохраняются.

### Примеры ручной проверки

**Пример 1. Основной пример.** Проверяет основной результат алгоритма на конкретном вводе.

Ввод:

```text
5
3 -1 2 0 3
```

Ожидаемый вывод:

```text
7
```

**Пример 2. Граничный пример.** Проверяет специальный или граничный случай входных данных.

Ввод:

```text
2
9 2
```

Ожидаемый вывод:

```text
11
```

**Пример 3. Сумма больше int.** Аккумулятор должен быть long.

Ввод:

```text
2
2147483647 2147483647
```

Ожидаемый вывод:

```text
4294967294
```
