## Задача 14. Сортировка вставками

### Условие

Дан массив целых чисел. Требуется отсортировать его
по невозрастанию методом вставок.

### Идея решения

Первый элемент считается отсортированной частью массива.

Начиная со второго элемента, очередное значение сохраняется
во временную переменную. В отсортированной части все элементы,
меньшие сохранённого значения, сдвигаются на одну позицию вправо.

На освободившееся место записывается сохранённое значение.
После каждого шага обработанная часть массива упорядочена
по невозрастанию.

Сохранение очередного значения во временной переменной
не позволяет потерять его при сдвиге элементов.

### Асимптотика

**Время — O(n²) в худшем случае, O(n) в лучшем.**

В худшем случае очередной элемент перемещается через всю
обработанную часть. Общее число сдвигов может достигать n(n−1)/2.

Если массив уже отсортирован по невозрастанию,
внутренний цикл не выполняет сдвигов.

**Общая память — O(n).**

Массив хранится в памяти. Дополнительная память сортировки — O(1).

### Примеры ручной проверки

**1. Обычная сортировка**

Ввод:

```text
5
3 1 5 2 4
```

Ожидаемый вывод:

```text
5 4 3 2 1
```

Проверяется требуемое направление сортировки.

**2. Отрицательные числа и повторы**

Ввод:

```text
5
-2 3 -2 0 3
```

Ожидаемый вывод:

```text
3 3 0 -2 -2
```

**3. Уже правильный порядок**

Ввод:

```text
4
9 7 4 1
```

Ожидаемый вывод:

```text
9 7 4 1
```

Проверяется лучший случай без сдвигов.
