## Задача 5. Сумма элементов на чётных позициях

### Условие

Дан массив из n целых чисел. Требуется найти сумму элементов
с чётными индексами: 0, 2, 4 и так далее.

Индексация начинается с нуля. Учитывается чётность индекса,
а не самого значения элемента.

### Идея решения

Сначала считывается размер n, затем элементы сохраняются
в массив numbers.

Суммируются элементы на индексах 0, 2, 4 и далее. Чётность самих значений не учитывается.
Для суммы используется long, чтобы избежать переполнения int.

### Асимптотика

**Время — O(n).**

Чтение требует O(n), суммирование ceil(n/2) элементов — O(n). Итоговая сложность O(n).

**Память — O(n).**

Для хранения входных данных создаётся массив из n элементов.
Остальные переменные занимают O(1) памяти.

### Примеры ручной проверки

**1. Массив нечётной длины**

Ввод:

```text
5
1 2 3 4 5
```

Ожидаемый вывод:

```text
9
```

Складываются элементы с индексами 0, 2 и 4: 1 + 3 + 5 = 9.

**2. Проверка выбора по индексу**

Ввод:

```text
4
1 100 3 200
```

Ожидаемый вывод:

```text
4
```

В сумму входят значения 1 и 3, поскольку их индексы чётные.
Значения 100 и 200 не учитываются.

**3. Отрицательные значения**

Ввод:

```text
5
-1 8 -2 8 -3
```

Ожидаемый вывод:

```text
-6
```

Отрицательные элементы на чётных индексах также включаются в сумму:
−1 + (−2) + (−3) = −6.

**4. Сумма, превышающая диапазон int**

Ввод:

```text
3
2147483647 0 2147483647
```

Ожидаемый вывод:

```text
4294967294
```

Результат превышает максимальное значение int,
но помещается в long.

**5. Минимальный допустимый размер**

Ввод:

```text
2
7 100
```

Ожидаемый вывод:

```text
7
```

При n = 2 единственный чётный индекс — 0.
