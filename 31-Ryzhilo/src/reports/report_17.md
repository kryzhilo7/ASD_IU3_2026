## Задача 17. Сортировка по сумме цифр

### Условие

Дан массив неотрицательных целых чисел.
Требуется отсортировать его по возрастанию суммы цифр.

Если суммы цифр равны, исходный порядок таких элементов
должен сохраниться.

### Идея решения

Используется стабильная сортировка слиянием.

Для сравнения чисел вычисляются суммы их цифр.
Последняя цифра получается через остаток от деления на 10,
после чего число делится на 10 без остатка.
Для нуля сумма цифр равна нулю.

При слиянии выбирается число с меньшей суммой цифр.
Если суммы равны, первым берётся элемент левой половины.

Такое правило сохраняет исходный порядок элементов
с одинаковыми суммами цифр.

### Асимптотика

**Время — O(n log n) для чисел типа int.**

Сортировка выполняет O(n log n) сравнений.
Неотрицательное число типа int содержит не более десяти цифр,
поэтому вычисление суммы цифр имеет ограниченную стоимость.

**Общая и дополнительная память — O(n).**

Создаётся временный буфер длины n.
Стек рекурсии требует O(log n).

### Примеры ручной проверки

**1. Разные суммы цифр**

Ввод:

```text
4
99 12 5 0
```

Ожидаемый вывод:

```text
0 12 5 99
```

Суммы цифр равны соответственно 0, 3, 5 и 18.

**2. Сохранение исходного порядка**

Ввод:

```text
7
21 12 3 30 4 40 0
```

Ожидаемый вывод:

```text
0 21 12 3 30 4 40
```

Числа 21, 12, 3 и 30 имеют сумму цифр 3
и сохраняют взаимный порядок. Аналогично сохраняется порядок 4 и 40.

**3. Только нули**

Ввод:

```text
3
0 0 0
```

Ожидаемый вывод:

```text
0 0 0
```

Проверяется обработка нуля и одинаковых ключей сортировки.
