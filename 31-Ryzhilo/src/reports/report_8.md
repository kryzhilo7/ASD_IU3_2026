## Задача 8. Фильтрация по знаку

### Условие

Дан массив целых чисел. Требуется сформировать два массива:
из положительных и из отрицательных элементов.

Порядок внутри каждой группы должен совпадать с исходным.
Нули не включаются ни в одну группу.

### Идея решения

При чтении исходного массива подсчитываются количества
положительных и отрицательных элементов.

Затем создаются два массива соответствующих размеров.
При повторном проходе положительные числа записываются
в первый массив, отрицательные — во второй.

Обход слева направо сохраняет порядок элементов внутри групп.
Нули пропускаются.

Положительные значения выводятся на первой строке,
отрицательные — на второй. Для формирования строк
используется StringBuilder.

### Асимптотика

**Время — O(n).**

Выполняется постоянное число линейных проходов:
чтение, распределение по группам и формирование вывода.

**Память — O(n).**

Хранятся исходный массив, массивы двух групп и строки результата.
Общее количество элементов в двух группах не превышает n.

### Примеры ручной проверки

**1. Разные знаки и нули**

Ввод:

```text
7
3 -2 0 5 -7 0 1
```

Ожидаемый вывод:

```text
3 5 1
-2 -7
```

Проверяются пропуск нулей и сохранение порядка.

**2. Только положительные числа**

Ввод:

```text
3
1 2 3
```

Ожидаемый вывод: первая строка содержит `1 2 3`,
вторая строка пустая.

Проверяется отсутствие отрицательной группы.

**3. Только нули**

Ввод:

```text
3
0 0 0
```

Ожидаемый вывод — две пустые строки.
Обе группы должны остаться пустыми.
