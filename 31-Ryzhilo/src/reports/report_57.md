# Задача 57. Спиральный обход матрицы

### Условие и формат

Требуется получить: элементы матрицы, обойдённые по спирали от левого верхнего угла по часовой стрелке.

**Ввод:** Два положительных размера n m, затем n строк по m целых чисел.

### Идея решения

Обходить верхнюю строку, правый столбец, нижнюю строку и левый столбец рамки. Сужать границы и проверять остаток перед каждым обратным проходом.

### Асимптотика

- Время: O(nm).
- Память: O(nm).

Обрабатывается n*m ячеек; число проходов постоянно. Хранятся исходная матрица и последовательность из n*m элементов.

### Примеры ручной проверки

**Пример 1. Основной пример.** Проверяет основной результат алгоритма на конкретном вводе.

Ввод:

```text
2 3
1 2 3
4 5 6
```

Ожидаемый вывод:

```text
1 2 3 6 5 4
```

**Пример 2. Граничный пример.** Проверяет специальный или граничный случай входных данных.

Ввод:

```text
3 1
1
2
3
```

Ожидаемый вывод:

```text
1 2 3
```

**Пример 3. Одна строка.** Элементы тонкой матрицы нельзя обходить повторно.

Ввод:

```text
1 4
1 2 3 4
```

Ожидаемый вывод:

```text
1 2 3 4
```
