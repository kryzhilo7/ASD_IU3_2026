## Задача 4. Все индексы элемента

**Идея.** Один проход слева направо: индекс каждого элемента, равного `x`, дописываем в `StringBuilder`
через пробел. Так как обход идёт по возрастанию индексов, сортировка результата не нужна.
Результат — последовательность неизвестной заранее длины, поэтому её накапливаем в `StringBuilder`, а не
в массиве с догоном размера и не в `ArrayList<Integer>` (лишняя упаковка `int` в `Integer`).

**Асимптотика.** Один проход, `n` сравнений и не более `k` дописываний (`k` — число вхождений, `k ≤ n`):
`Θ(n)`. Память: массив `O(n)`, строка ответа `O(k)`. Если вхождений нет, выводится пустая строка.

| Вход                        | Ответ        | Почему важен                                                    |
|-----------------------------|--------------|-----------------------------------------------------------------|
| `[5, 1, 5, 2, 5]`, `x = 5`  | `0 2 4`      | базовый случай, порядок возрастания                             |
| `[1, 2, 3]`, `x = 7`        | пустая строка| элемента нет: не должно быть ошибки                             |
| `[9, 9, 9, 9]`, `x = 9`     | `0 1 2 3`    | все элементы совпадают, `k = n`: максимальный размер ответа     |
| `[3, 1, 2, 3]`, `x = 3`     | `0 3`        | совпадения на обеих границах массива: типичная ошибка off-by-one|
| 99 999 элементов `x`        | все индексы  | верхняя граница `n`; сборка вывода не должна быть `O(n²)`       |
