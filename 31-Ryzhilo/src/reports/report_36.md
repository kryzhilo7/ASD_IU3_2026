# Задача 36. Бегущая сумма

### Условие и формат

Требуется получить: массив той же длины, где i-й элемент равен сумме первых i + 1 элементов исходного массива.

**Ввод:** Размер n, затем n целых элементов массива.

### Идея решения

Во время чтения обновлять long-сумму и сразу печатать очередной префикс.

### Асимптотика

- Время: O(n).
- Память: O(1).

Выполняется постоянное число линейных проходов по n элементам. Достаточно постоянного числа аккумуляторов и индексов; исходные элементы не сохраняются.

### Примеры ручной проверки

**Пример 1. Основной пример.** Проверяет основной результат алгоритма на конкретном вводе.

Ввод:

```text
5
3 -1 2 0 3
```

Ожидаемый вывод:

```text
3 2 4 4 7
```

**Пример 2. Граничный пример.** Проверяет специальный или граничный случай входных данных.

Ввод:

```text
2
9 2
```

Ожидаемый вывод:

```text
9 11
```

**Пример 3. Префикс больше int.** Суммы должны храниться в long.

Ввод:

```text
2
2147483647 2147483647
```

Ожидаемый вывод:

```text
2147483647 4294967294
```
