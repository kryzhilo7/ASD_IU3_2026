# Задача 50. Сумма столбцов матрицы

### Условие и формат

Требуется получить: массив из m элементов — сумм столбцов матрицы.

**Ввод:** Два положительных размера n m, затем n строк по m целых чисел.

### Идея решения

Хранить по одной long-сумме для каждого столбца и обновлять при чтении строк.

### Асимптотика

- Время: O(nm).
- Память: O(m).

Обрабатывается n*m ячеек; число проходов постоянно. Нужны m сумм столбцов.

### Примеры ручной проверки

**Пример 1. Основной пример.** Проверяет основной результат алгоритма на конкретном вводе.

Ввод:

```text
2 3
1 2 3
4 5 6
```

Ожидаемый вывод:

```text
5 7 9
```

**Пример 2. Граничный пример.** Проверяет специальный или граничный случай входных данных.

Ввод:

```text
3 1
1
2
3
```

Ожидаемый вывод:

```text
6
```

**Пример 3. Сумма столбца больше int.** Проверяются один столбец и long-аккумулятор.

Ввод:

```text
2 1
2147483647
2147483647
```

Ожидаемый вывод:

```text
4294967294
```
