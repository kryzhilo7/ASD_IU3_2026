## Задача 16. Сортировка по модулю

### Условие

Дан массив целых чисел. Требуется отсортировать его
по неубыванию модуля элементов.

При равных модулях отрицательное значение должно идти
раньше положительного.

### Идея решения

Используется сортировка слиянием.

Массив рекурсивно делится на две половины.
После сортировки половин они объединяются во временном массиве,
затем результат копируется обратно.

При сравнении сначала рассматриваются модули чисел.
Если модули равны, сравниваются сами значения:
меньшее, то есть отрицательное, располагается раньше.

Перед вычислением модуля число преобразуется к long.
Это необходимо для Integer.MIN_VALUE, положительный модуль
которого не помещается в int.

### Асимптотика

**Время — O(n log n).**

На каждом уровне рекурсии суммарно обрабатывается O(n) элементов.
Количество уровней — O(log n).

**Общая и дополнительная память — O(n).**

Используются исходный массив и буфер длины n.
Стек рекурсии занимает O(log n), что не меняет общую оценку.

### Примеры ручной проверки

**1. Разные модули и знаки**

Ввод:

```text
6
-3 1 0 2 -1 3
```

Ожидаемый вывод:

```text
0 -1 1 2 -3 3
```

Проверяются порядок модулей и выбор отрицательного при равенстве.

**2. Одинаковые модули**

Ввод:

```text
4
2 -2 2 -2
```

Ожидаемый вывод:

```text
-2 -2 2 2
```

Все повторения должны сохраниться.

**3. Крайние значения int**

Ввод:

```text
3
-2147483648 2147483647 0
```

Ожидаемый вывод:

```text
0 2147483647 -2147483648
```

Модуль Integer.MIN_VALUE больше модуля Integer.MAX_VALUE.
