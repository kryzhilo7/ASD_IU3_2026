## Задача 11. Ближайший к среднему

### Условие

Дан массив целых чисел. Требуется вывести элемент,
ближайший к среднему арифметическому массива.

Если несколько элементов имеют одинаковое расстояние
до среднего, выбирается первый по индексу.
Среднее может быть дробным.

### Идея решения

При чтении массив сохраняется и вычисляется сумма S типа long.

Вместо расстояния |a[i] − S/n| сравнивается величина:

```text
|a[i] * n − S|
```

Это исходное расстояние, умноженное на положительное n.
Такое преобразование сохраняет порядок расстояний
и позволяет избежать деления и ошибок округления.

Первым кандидатом становится элемент с индексом 0.
При дальнейшем проходе ответ обновляется только тогда,
когда найдено строго меньшее расстояние.

При равенстве расстояний прежний ответ сохраняется,
поэтому выбирается первый подходящий элемент.

Вычисления выполняются в long. При ограничениях задачи
сумма и масштабированные расстояния помещаются в этот тип.

### Асимптотика

**Время — O(n).**

Один проход нужен для чтения и суммы,
ещё один — для поиска ближайшего элемента.

**Память — O(n).**

Хранится исходный массив.
Остальные переменные занимают O(1).

### Примеры ручной проверки

**1. Элемент равен среднему**

Ввод:

```text
3
1 4 7
```

Ожидаемый вывод:

```text
4
```

Среднее равно 4, расстояние до выбранного элемента равно нулю.

**2. Дробное среднее**

Ввод:

```text
3
1 2 4
```

Ожидаемый вывод:

```text
2
```

Среднее равно 7/3. Ближайший элемент — 2.

**3. Равные расстояния**

Ввод:

```text
2
8 2
```

Ожидаемый вывод:

```text
8
```

Среднее равно 5. Оба числа находятся на расстоянии 3,
поэтому выбирается первое.
