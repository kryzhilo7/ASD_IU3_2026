# Задача 52. Минимум в каждом столбце

### Условие и формат

Требуется получить: массив из m элементов — минимальных значений в каждом столбце.

**Ввод:** Два положительных размера n m, затем n строк по m целых чисел.

### Идея решения

Хранить минимум каждого столбца; начальные значения Integer.MAX_VALUE.

### Асимптотика

- Время: O(nm).
- Память: O(m).

Обрабатывается n*m ячеек; число проходов постоянно. Нужны m минимумов столбцов.

### Примеры ручной проверки

**Пример 1. Основной пример.** Проверяет основной результат алгоритма на конкретном вводе.

Ввод:

```text
2 3
1 2 3
4 5 6
```

Ожидаемый вывод:

```text
1 2 3
```

**Пример 2. Граничный пример.** Проверяет специальный или граничный случай входных данных.

Ввод:

```text
3 1
1
2
3
```

Ожидаемый вывод:

```text
1
```

**Пример 3. Повторяющиеся минимумы.** Минимум определяется независимо для каждого столбца.

Ввод:

```text
2 2
-3 4
-3 2
```

Ожидаемый вывод:

```text
-3 2
```
