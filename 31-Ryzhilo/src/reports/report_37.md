# Задача 37. Разворот массива

### Условие и формат

Требуется получить: массив, записанный в обратном порядке.

**Ввод:** Размер n, затем n целых элементов массива.

### Идея решения

Менять местами симметричные элементы двумя указателями.

### Асимптотика

- Время: O(n).
- Память: O(n); дополнительно O(1).

Выполняется постоянное число линейных проходов по n элементам. Исходный массив хранит n значений. Преобразование выполняется на месте, сверх массива используется O(1) памяти.

### Примеры ручной проверки

**Пример 1. Основной пример.** Проверяет основной результат алгоритма на конкретном вводе.

Ввод:

```text
5
3 -1 2 0 3
```

Ожидаемый вывод:

```text
3 0 2 -1 3
```

**Пример 2. Граничный пример.** Проверяет специальный или граничный случай входных данных.

Ввод:

```text
2
9 2
```

Ожидаемый вывод:

```text
2 9
```

**Пример 3. Нечётная длина.** Центральный элемент сохраняется при попарных обменах.

Ввод:

```text
5
1 2 3 4 5
```

Ожидаемый вывод:

```text
5 4 3 2 1
```
