# Задача 29. Мода массива

### Условие и формат

Требуется получить: наиболее часто встречающийся элемент. Если несколько — вывести наименьший по значению.

**Ввод:** Размер n, затем n целых элементов массива.

### Идея решения

После сортировки найти самую длинную группу равных значений. Обновление только при строго большей частоте оставляет минимальную моду.

### Асимптотика

- Время: O(n log n).
- Память: O(n); дополнительно O(1).

Построение двоичной кучи линейно, затем выполняется O(n) извлечений с восстановлением высотой O(log n). Последующие выбор элемента, сравнение или подсчёт не превосходят O(n). Сортировка выполняется на месте.

### Примеры ручной проверки

**Пример 1. Основной пример.** Проверяет основной результат алгоритма на конкретном вводе.

Ввод:

```text
5
3 -1 2 0 3
```

Ожидаемый вывод:

```text
3
```

**Пример 2. Граничный пример.** Проверяет специальный или граничный случай входных данных.

Ввод:

```text
2
9 2
```

Ожидаемый вывод:

```text
2
```

**Пример 3. Один элемент.** В задаче 29 отдельно разрешено n = 1.

Ввод:

```text
1
42
```

Ожидаемый вывод:

```text
42
```
