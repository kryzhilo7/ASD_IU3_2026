# Задача 59. Определитель матрицы 3×3

### Условие и формат

Требуется получить: определитель матрицы.

**Ввод:** Девять целых чисел матрицы 3×3, без ввода размеров.

### Идея решения

Вычислить три алгебраических дополнения первой строки и сложить их произведения. BigInteger предотвращает переполнение произведений трёх int.

### Асимптотика

- Время: O(1) для 3×3.
- Память: O(1).

Размер матрицы фиксирован: вычисляется постоянное число произведений и сумм. Для элементов int длина точного результата ограничена.

### Примеры ручной проверки

**Пример 1. Основной пример.** Проверяет основной результат алгоритма на конкретном вводе.

Ввод:

```text
1 0 0
0 1 0
0 0 1
```

Ожидаемый вывод:

```text
1
```

**Пример 2. Граничный пример.** Проверяет специальный или граничный случай входных данных.

Ввод:

```text
-2147483648 1 0
2 -1 0
0 0 3
```

Ожидаемый вывод:

```text
6442450938
```

**Пример 3. Вырожденная матрица.** При двух одинаковых строках определитель равен нулю.

Ввод:

```text
1 2 3
1 2 3
4 5 6
```

Ожидаемый вывод:

```text
0
```
