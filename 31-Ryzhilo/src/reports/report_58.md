# Задача 58. Заполнение матрицы змейкой

### Условие и формат

Требуется получить: матрица n x m, заполненная числами от 1 до n x m змейкой по строкам: первая строка слева направо, вторая — справа налево и т. д.

**Ввод:** Два положительных размера n m.

### Идея решения

Значение в чётной строке: i*m+j+1, в нечётной: i*m+m−j. Вычислять и печатать сразу.

### Асимптотика

- Время: O(nm).
- Память: O(1).

Обрабатывается n*m ячеек; число проходов постоянно. Значения вычисляются и выводятся сразу, матрица не сохраняется.

### Примеры ручной проверки

**Пример 1. Основной пример.** Проверяет основной результат алгоритма на конкретном вводе.

Ввод:

```text
2 3
```

Ожидаемый вывод:

```text
1 2 3
6 5 4
```

**Пример 2. Граничный пример.** Проверяет специальный или граничный случай входных данных.

Ввод:

```text
3 3
```

Ожидаемый вывод:

```text
1 2 3
6 5 4
7 8 9
```

**Пример 3. Нечётная строка идёт обратно.** Нумерация непрерывна, направление меняется по строкам.

Ввод:

```text
2 3
```

Ожидаемый вывод:

```text
1 2 3
6 5 4
```
