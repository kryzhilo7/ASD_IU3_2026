# Задача 60. Острова из единиц

### Условие и формат

Требуется получить: количество «островов» — групп связанных единиц (связь по горизонтали и вертикали, не по диагонали).

**Ввод:** Два положительных размера n m, затем n строк по m целых чисел.

### Идея решения

Из каждой ещё не посещённой единицы запустить BFS по четырём соседям. Очередь — массив индексов; ячейку обнулять при добавлении, поэтому каждая ячейка посещается один раз.

### Асимптотика

- Время: O(nm).
- Память: O(nm).

Каждая клетка добавляется в очередь не более одного раза, при обработке проверяются четыре соседа. Матрица и очередь требуют O(nm) памяти; рекурсивного обхода нет.

### Примеры ручной проверки

**Пример 1. Основной пример.** Проверяет основной результат алгоритма на конкретном вводе.

Ввод:

```text
2 3
1 0 1
1 0 1
```

Ожидаемый вывод:

```text
2
```

**Пример 2. Граничный пример.** Проверяет специальный или граничный случай входных данных.

Ввод:

```text
3 1
1
0
1
```

Ожидаемый вывод:

```text
2
```

**Пример 3. Диагональные единицы.** Связность только по вертикали и горизонтали: это два острова.

Ввод:

```text
2 2
1 0
0 1
```

Ожидаемый вывод:

```text
2
```
