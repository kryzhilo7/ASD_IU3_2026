# Задача 49. Сумма строк матрицы

### Условие и формат

Требуется получить: массив из n элементов — сумм строк матрицы.

**Ввод:** Два положительных размера n m, затем n строк по m целых чисел.

### Идея решения

Читать каждую строку, накапливать её сумму в long и печатать.

### Асимптотика

- Время: O(nm).
- Память: O(1).

Обрабатывается n*m ячеек; число проходов постоянно. Достаточно аккумулятора текущей строки.

### Примеры ручной проверки

**Пример 1. Основной пример.** Проверяет основной результат алгоритма на конкретном вводе.

Ввод:

```text
2 3
1 2 3
4 5 6
```

Ожидаемый вывод:

```text
6 15
```

**Пример 2. Граничный пример.** Проверяет специальный или граничный случай входных данных.

Ввод:

```text
3 1
1
2
3
```

Ожидаемый вывод:

```text
1 2 3
```

**Пример 3. Сумма строки больше int.** Сумма хранится в long.

Ввод:

```text
1 2
2147483647 2147483647
```

Ожидаемый вывод:

```text
4294967294
```
