# Задача 31. Скалярное произведение

### Условие и формат

Требуется получить: скалярное произведение

**Ввод:** Размер n, затем n элементов первого массива и n элементов второго, без повторного размера.

### Идея решения

Сохранить первый массив, второй читать по элементам. Каждое произведение вычислять в long, сумму — в BigInteger.

### Асимптотика

- Время: O(n) арифметических операций.
- Память: O(n).

На элемент выполняется постоянное число арифметических операций. В памяти хранится первый массив и аккумулятор. BigInteger не имеет постоянной битовой стоимости: она зависит от длины чисел; при заданных ограничениях n и int длина накопленных результатов ограничена.

### Примеры ручной проверки

**Пример 1. Основной пример.** Проверяет основной результат алгоритма на конкретном вводе.

Ввод:

```text
5
3 -1 2 0 3
2147483647 -1 0 3 -2147483648
```

Ожидаемый вывод:

```text
-2
```

**Пример 2. Граничный пример.** Проверяет специальный или граничный случай входных данных.

Ввод:

```text
3
-2147483648 -2147483648 -2147483648
-2147483648 -2147483648 -2147483648
```

Ожидаемый вывод:

```text
13835058055282163712
```
