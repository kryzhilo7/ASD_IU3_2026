# Задача 30. Дисперсия

### Условие и формат

Требуется получить: выборочную дисперсию по формуле.

**Ввод:** Размер n, затем n целых элементов массива.

### Идея решения

Алгоритм Уэлфорда обновляет среднее и сумму квадратов отклонений за один проход. Принята исправленная выборочная дисперсия: сумма квадратов отклонений / (n−1).

### Асимптотика

- Время: O(n).
- Память: O(1).

Выполняется постоянное число линейных проходов по n элементам. Достаточно постоянного числа аккумуляторов и индексов; исходные элементы не сохраняются.

Принята формула `S² = Σ(xᵢ − x̄)² / (n − 1)`. Для вычислений используется алгоритм Уэлфорда. Эта формула требует подтверждения, поскольку в условии она отсутствует.

### Примеры ручной проверки

**Пример 1. Основной пример.** Проверяет основной результат алгоритма на конкретном вводе.

Ввод:

```text
5
3 -1 2 0 3
```

Ожидаемый вывод:

```text
3.3
```

**Пример 2. Граничный пример.** Проверяет специальный или граничный случай входных данных.

Ввод:

```text
3
2147483647 2147483646 2147483645
```

Ожидаемый вывод:

```text
1
```

**Пример 3. Проверка знаменателя.** Для принятого знаменателя n−1 ответ равен 1; при n ответ был бы 2/3.

Ввод:

```text
3
1 2 3
```

Ожидаемый вывод:

```text
1.0
```
