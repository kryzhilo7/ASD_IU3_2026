## Задача 7. Второй максимум

### Условие

Дан массив из n различных целых чисел.
Требуется найти второй по величине элемент.

### Идея решения

После чтения массива первые два элемента используются
для начального определения максимума и второго максимума.

Далее рассматриваются остальные элементы.

Если очередное число больше максимума, прежний максимум
становится вторым, а новое число — первым.

Если число не больше максимума, но больше второго максимума,
обновляется только второй максимум.

После каждого шага переменные содержат два наибольших значения
среди уже рассмотренных элементов.

### Асимптотика

**Время — O(n).**

Чтение массива и поиск двух наибольших значений требуют
линейного числа операций.

**Память — O(n).**

В данной реализации хранится весь массив.
Для самого поиска достаточно O(1) дополнительных переменных.

### Примеры ручной проверки

**1. Неупорядоченный массив**

Ввод:

```text
5
3 9 1 7 2
```

Ожидаемый вывод:

```text
7
```

Максимум равен 9, второй максимум — 7.

**2. Отрицательные числа**

Ввод:

```text
4
-5 -2 -9 -1
```

Ожидаемый вывод:

```text
-2
```

Проверяется правильная инициализация без использования нуля.

**3. Два элемента**

Ввод:

```text
2
2147483647 -2147483648
```

Ожидаемый вывод:

```text
-2147483648
```

При двух различных элементах второй максимум — меньший из них.
